# Amorvi Backend

Local backend for the Amorvi React Native app.

## Stack

- Node.js + TypeScript
- Express API
- JSON file datastore for local development
- PostgreSQL JSONB datastore when `DATABASE_URL` is set
- JWT auth

## Free deployment (Render + Supabase)

The repository includes a Render Blueprint in `../render.yaml`. It deploys the API as a free Docker web service at `https://amorvi.onrender.com`.

The production API requires `DATABASE_URL`; it refuses to start without it so user data is not written to Render's temporary filesystem. Create a free Supabase Postgres project, copy its **Session pooler** connection string, and set it as `DATABASE_URL` in Render. The API creates its JSONB state table on first startup. Do not commit the connection string.

In Render, create a Blueprint instance from this repository and enter `DATABASE_URL` when prompted. `JWT_SECRET` is generated by the Blueprint. Add `GOOGLE_WEB_CLIENT_ID` as a Render environment variable if Google sign-in is enabled. After the first deploy, check `https://amorvi.onrender.com/health`.

The free Render service sleeps after 15 minutes without traffic and can take about a minute to wake. Supabase Free may pause a project after a week with too little activity; its data is retained when paused. These free tiers are suitable for a prototype, not a production service.

## Setup

```sh
cd backend
npm install
npm run seed
npm run dev
```

## Google Sign-In

Create OAuth clients in Google Cloud for:

- Android app: package name `com.love_alarm_app`
- Web app: used for token verification

Paste the Web Client ID in:

```txt
backend/.env
src/config/auth.ts
```

```txt
GOOGLE_WEB_CLIENT_ID="your-google-web-client-id.apps.googleusercontent.com"
```

After installing native Google Sign-In, rebuild the app:

```sh
npm run android
```

For iOS, run pods after installing:

```sh
cd ios
bundle exec pod install
```

Health check:

```sh
curl http://localhost:4000/health
```

Seed login:

```txt
email: emily@amorvi.test
password: password123
```

## Mobile API URL

For Android emulator, use:

```txt
http://10.0.2.2:4000
```

For iOS simulator, use:

```txt
http://localhost:4000
```

For a real device, use your computer LAN IP, for example:

```txt
http://192.168.1.20:4000
```
